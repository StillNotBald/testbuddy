Screens not drawn

Only the repository, run detail and test execution are drawn here. The other screens are reviewed in the real build, which uses the recommended defaults. Their decisions are still in the table above.

Where these mockups differ from DESIGN.md

  • Sidebar active item uses a filled background, bold text and an accent icon instead of a 3px accent marker (a coloured side stripe is a known visual weak point; the tokens are unchanged).
  • Pass rate is shown as passed out of all tests with completion beside it (D23), so the Web smoke run reads 53% passed and 63% complete. mock-data.md says "62% done" for the same counts; 24 of 38 is 63%.
  • Repository shows the mock-data counts (Login 12, 120 cases), not the wireframe's 18 and 212. The list scrolls with a count instead of page buttons (D3).
  • Statuses are Passed, Failed, Blocked, Retest, Untested (default Untested). Skipped stays an open question (D12).
  • CI tokens are drawn as separate tokens with scope and expiry (D25), the project list is at /projects, and the workspace switch sits in the top bar.
  • Phones are read-only for everyone including testers (D13). The execution mockup has a mock switch to preview the quick-result option.
