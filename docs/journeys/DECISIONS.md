# TestBuddy journey decisions

Owner decision, 2026-11-04 (in chat): "for the open questions, please follow standard practice." Every open question and cell in the four journey maps was answered with the recommended answer. Each answer is recorded as "owner (standard practice, 2026-11-04)" in the map's decisions file (`docs/journeys/<map>.decisions.yaml`, appended by `journey-mapping tool decide`) and the maps point at it with `decisions:`.

45 decisions: 8 run-lifecycle, 9 test-result-lifecycle, 11 case-lifecycle, 17 ci-execution.

Answers the owner list did not cover (decided by the same rule, industry standard): Q-CASE-2 reactivating an already active case is ignored; Q-CASE-6 a deprecated case may also be moved; Q-CASE-4 and Q-CASE-11 are split by snapshot state (see decisions files); Q-CI-4 late system events on a finished execution are ignored; Q-CI-10 create/revoke on a token record that is already active or revoked are ignored (a new token is a new record).

Journey-map side effects: guard `run_open` added to TST-5..9 (Q-RES-4) and ATT-1 (Q-RES-5) in `test-result-lifecycle.yaml`.
